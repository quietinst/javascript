# Task 01 — Image Gallery Modal

## Objective

Build an image gallery rendered dynamically from an array of data, using event delegation to open a lightbox modal with the full-size image on click.

### Concepts

- Event delegation
- Array methods (`map()`, `join()`)
- Template literals
- `data-*` attributes
- `preventDefault()`
- Third-party library integration (basicLightbox via CDN)
