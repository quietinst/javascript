# Module 09 — NPM and Modules

🔗 [Live demo](https://quietinst.github.io/javascript/module-09-npm-and-modules/dist/)

This module covers the JSON format, Web Storage, Node.js and npm, and ECMAScript Modules — installing and importing third-party packages instead of relying on CDN scripts.

Built with Vite. To run locally:

```bash
npm install
npm run dev
```

To publish the live demo, run `npm run build` and commit the generated `dist` folder.

## Tasks

- Task 01 — Image Gallery
- Task 02 — Feedback Form

## Topics

- JSON (`JSON.stringify()` / `JSON.parse()`)
- Web Storage (`localStorage`)
- Node.js and npm
- `package.json` and `package-lock.json`
- ECMAScript Modules (`import` / `export`)
- Installing and using third-party npm packages
- Vite as a build tool
