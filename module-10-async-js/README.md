# Module 10 — Async JS

🔗 [Live demo](https://quietinst.github.io/javascript/module-10-async-js/dist/)

This module covers synchronous vs. asynchronous code, `setTimeout`/`setInterval`, and Promises — how they work and the core methods of the `Promise` class.

Built with Vite. To run locally:

```bash
npm install
npm run dev
```

To publish the live demo, run `npm run build` and commit the generated `dist` folder.

## Tasks

- Task 01 — Countdown Timer
- Task 02 — Promise Generator

## Topics

- Synchronous vs. asynchronous code
- `setTimeout()` / `setInterval()`
- Promises (`resolve` / `reject`)
- `Promise` class methods
- flatpickr (date picker library)
- iziToast (notification library)
