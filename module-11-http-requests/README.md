# Module 11 — HTTP Requests

🔗 [Live demo](https://quietinst.github.io/javascript/module-11-http-requests/dist/)

This module covers HTTP/HTTPS, the main HTTP methods, CRUD, and talking to a backend — practiced by building an image search app against the Pixabay API.

Built with Vite. To run locally:

```bash
cp .env.example .env   # add your own Pixabay API key
npm install
npm run dev
```

To publish the live demo, run `npm run build` and commit the generated `dist` folder.

- Task 01 — Image Search

- HTTP vs. HTTPS
- HTTP methods, CRUD
- REST APIs (Pixabay)
