# Task 01 — Image Search

## Objective

Build an image search app: on form submit, fetch matching photos from the Pixabay API with Axios, render them as a gallery with a SimpleLightbox modal, and show a loader while the request is in flight.

### Concepts

- Axios (`GET` requests, query parameters)
- Modular architecture (`pixabay-api.js`, `render-functions.js`, `main.js`)
- Promises (`then()` / `catch()`)
- SimpleLightbox
- iziToast
- CSS-only loading spinner
